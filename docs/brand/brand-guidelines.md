# KodRoot

The symbol is a root sign. The hook and the bar are the radical, drawn as a monoline mark rather than taken from a math font. In the lockup the bar continues over the name. That is where an expression sits when a root is taken of it. KodRoot is that expression.

Alone, the symbol is still a root sign. It does not need a second meaning.

## Files

- `index.html` — the identity, the logo variations, the business cards, and the door sticker
- `cards/` — print files for the light and dark cards, with 3 mm bleed
- `stickers/` — the same size, with the logo, services, contact, site, and code on one face
- `logos/` — primary, light, dark, monochrome, symbol, favicon, and the repeating pattern
- `colors.md` — palette
- `typography.md` — the wordmark, and the face used for supporting text

Primary and light are the same file. The mark is drawn for paper. On a dark ground the sign stays Burgundy and the name uses paper.
