# KodRoot

Official website for KodRoot, a software development company founded in Kosovo.

This repository currently contains the Next.js application after starter-template cleanup. Brand assets live in `public/brand/` and `app/fonts/`. Design tokens, full page sections, and the project inquiry form will follow in later stages.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4

Package manager: **npm** (`package-lock.json`).

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
npm start
```
